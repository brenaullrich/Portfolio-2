# Brena Ullrich — Portfolio

Static portfolio site (no build step). Open `index.html` or serve the folder:

```
python3 -m http.server 8000
```

- `index.html` — page markup
- `styles.css` — styles, including tablet/mobile breakpoints
- `main.js` — password gate, photobooth-strip animation, video lightbox
- `images/`, `videos/` — media assets

The password gate is client-side only (password: `social26`); it keeps casual visitors out but is not real access control.
